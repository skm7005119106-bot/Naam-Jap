# Naam Jap v32 — Fullscreen Premium UI

Built from the existing Naam Jap v29/v31 base without replacing the core app structure.

## v32 upgrades
- Full-width mobile layout with vertical scrolling where content requires it.
- Larger readable typography across Home, Jap, Naam, Profile, Sankalp and Settings.
- Jap screen uses the available viewport more fully.
- Larger centered 0–108 Jap circle with progress ring, tap flash and smooth interaction.
- Premium in-app certificates with user name, specific Jap Naam, milestone, completed count, date and unique certificate number.
- Premium A4 Print / Save PDF certificate layout.
- Large milestone-completion celebration.
- Milestone certificates record the currently selected Jap Naam instead of a generic "all" label.
- Fresh PWA icon set and v32 service-worker cache.

## Important
For true browser chrome/status-bar-free full-screen, install the PWA from Chrome's Add to Home screen / Install app flow. The normal browser tab will still show its address bar.
